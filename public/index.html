HyperFormula Edge Calc Service

Stateless spreadsheet calculations via HTTP. Formulas instead of code.

Powered by HyperFormula

Usage

Send a POST to /api/calc with a JSON body containing your data and formulas.

Single Formula Mode

Apply one formula to a dataset. Returns the computed value.

{
  "data": [
    ["value"],
    [10],
    [20],
    [30]
  ],
  "formula": "=SUM(A2:A4)"
}

Embedded Formulas Mode

Place formulas directly in data cells. Returns the full evaluated grid.

{
  "data": [
    ["a", "b", "sum"],
    [1, 2, "=A2+B2"],
    [3, 4, "=A3+B3"]
  ]
}

Return Modes

ModeDescription
"grid"Full dataset with all formulas evaluated
"value"Single computed value (default for single formula mode)
"results"Only cells that contained formulas, with their computed values
