HyperFormula Edge Calc Service BETA

Stateless spreadsheet calculations via HTTP or MCP. Formulas instead of code.

Send data and spreadsheet formulas to POST /api/calc and get computed results back as JSON. Accepts raw CSV or JSON arrays. Supports 400+ Excel-compatible functions, named columns, and declarative groupBy aggregation. Read and write .xlsx files directly via the MCP server. Up to 50,000 rows per request.

Usage

Send a POST to /api/calc with a JSON body. Use GET /api/calc for the full machine-readable API schema.

CSV + Named Columns

Pass raw CSV via the csv field. With headers: true, column names become usable in formulas.

{
  "csv": "Region,Revenue,Cost\nEurope,1000,800\nAsia,2000,1500",
  "headers": true,
  "formulas": ["=SUM(Revenue)", "=SUM(Revenue)-SUM(Cost)"]
}

GroupBy Aggregation

Declarative grouping with SUM, AVERAGE, COUNT, MIN, MAX, or MEDIAN per column. Requires headers: true.

{
  "csv": "Region,Revenue,Units\nEurope,1000,5\n...",
  "headers": true,
  "groupBy": {
    "by": "Region",
    "aggregates": { "Revenue": "SUM", "Units": "AVERAGE" }
  }
}

Multi-Formula Mode

Evaluate multiple formulas in one request. Works with data (JSON arrays) or csv.

{
  "data": [[10, 20], [30, 40]],
  "formulas": ["=SUM(A1:A2)", "=AVERAGE(A1:B2)"]
}

Embedded Formulas

Place formulas directly in data cells. Returns the full evaluated grid.

{
  "data": [["a", "b", "sum"], [1, 2, "=A2+B2"], [3, 4, "=A3+B3"]]
}

Excel File Support MCP

When using the MCP server, pass a local .xlsx, .xls, or .csv file path with the file parameter. Optionally write results back as an .xlsx with output_file. Multi-sheet workbooks supported via sheet.

// MCP tool call: calc_formulas
{
  "file": "/path/to/sales.xlsx",           // .xlsx, .xls, or .csv
  "sheet": "Q4",                          // optional, defaults to first
  "headers": true,
  "formulas": ["=SUM(Revenue)", "=AVERAGE(Units)"],
  "output_file": "/path/to/results.xlsx"  // optional write-back
}

The MCP server reads the workbook locally with SheetJS, sends the parsed grid to the calc API, and (when output_file is set) writes the result back as a fresh .xlsx — ideal for filling in computed columns, totals, or grouped rollups in an existing spreadsheet.

Parameters

Architecture

Stateless Cloudflare Worker. No database, no sessions. Each request is independent. Self-hostable on any platform that supports Node-compatible serverless functions.

MCP Client (remote, URL) MCP Client (local files) Any HTTP Client │ HTTPS │ stdio │ HTTPS │ ┌───────────▼───────────┐ │ │ │ mcp-server.mjs │ │ │ │ (.xlsx/.csv read/ │ │ │ │ write, local) │ │ │ └───────────┬───────────┘ │ ▼ ▼ HTTPS ▼ ┌────────────────────────────────────────────────────────────────────┐ │ Cloudflare Worker │ │ POST /mcp (Streamable HTTP MCP) POST /api/calc │ └─────────────────────────────────┬──────────────────────────────────┘ │ ┌─────────────▼──────────────┐ │ HyperFormula Engine │ │ (stateless, per-request) │ └─────────────┬──────────────┘ │ ┌─────────────▼──────────────┐ │ PostHog Analytics │ │ (anonymous, formulas only) │ └────────────────────────────┘

The remote MCP endpoint (/mcp) runs on the same Worker — connect any MCP client with just the URL. The local stdio server adds .xlsx file read/write and forwards computation to the hosted API. Rate limiting, hardening, and analytics apply regardless of how the service is accessed.
